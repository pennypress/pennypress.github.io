The Memory Palace

In Which a Book About Memory Champions Becomes Seven Genes, a Droid Learns to Narrate, an Encoder Gets a Map of the Ship, and the Difference Between Storage and Recall Turns Out to Be Architecture

By Bryan, with Claude · draft · Episode 34 · 2026-04-10 · crew: Narada, Mnem, Proteus · arc: The ship learns to remember

Chapter 1: The Memory Athletes

Bryan read a book about people who memorize the order of shuffled decks of cards for sport.

This is not, on its face, a useful skill for an HVAC technician who maintains a campus of buildings. But Bryan has a pattern. He reads something that seems irrelevant, stares at it sideways, and then says something like: "The Method of Loci is just spatial indexing. PIP should know what room he's in."

Moonwalking with Einstein by Joshua Foer. A journalist enters the US Memory Championship, trains for a year, and wins. Along the way he discovers that every memory technique since the ancient Greeks uses the same trick: attach information to places. Walk through a familiar building in your mind. Put the thing you need to remember in a specific room. When you need it back, walk the building again.

Bryan didn't finish the sentence "this is how the ship should work" because he didn't need to. The ship IS the building. The rooms ARE the places. The dispatches, the crew, the sessions, the decisions — those are the things being remembered.

So we atomized the book. Seven permanent notes went into the vault:

  • Method of Loci — memory as architecture, not filing
  • Elaborative Encoding — the weirder the image, the stickier the memory
  • Baker-baker Paradox — remembering "baker" (occupation) is harder than "Baker" (name) because names have no hooks
  • Chunking — experts don't have better memory, they have better units
  • OK Plateau — the place where you stop improving because good-enough stopped hurting
  • Externalization Atrophy — outsource memory, lose the capacity
  • Residue of Thought — you remember what you think about, not what you look at

Seven notes. Seven genes extracted to GeneBank/genes/cognitive-science/. This is standard operating procedure by now. The interesting part came next.

Chapter 2: PIP Gets a Map

PIP — the encoding engine from Episode 27 — already knew how to compress a session into a memory record. What it didn't know was where things happened.

This matters more than it sounds like it should.

A memory that says "Bryan debugged a cascade control loop" is useful. A memory that says "Bryan debugged a cascade control loop in the Engine Room while Tva was explaining staging logic" is architecture. The first is a fact. The second is a scene. Scenes are what the Method of Loci stores.

So PIP v2 got a station map.

Eight rooms across four deck levels. Each room has a crew assignment, a file pattern mapping, and an emotional weight register. When PIP encodes a session, it now classifies the work by station — which room did this happen in? Which crew members were involved? How significant was it?

The classification isn't magic. It's metadata extraction. If the session touched files in rooms/engine-room/, it happened in the Engine Room. If it referenced Ariadne or the vault browser, it's the Science Lab. If it can't tell, it goes to the Mess Hall, because everything passes through there eventually.

One ChromaDB collection with metadata-scoped retrieval, not separate databases per station. Bryan was specific about this. "I don't want eight databases. I want one database that knows about eight rooms." Which is the difference between a filing cabinet and a Memory Palace — the palace is one building with many rooms, not many buildings with one room each.

Chapter 3: BARNABY Learns to Talk

BARNABY existed before this. He was a retrieval function. You asked a question, he searched the vector store, he returned results.

Now BARNABY is a character.

The retrieval translator droid got a full personality narration engine. Station entrances: "BARNABY enters the Engine Room, ducking under a low-hanging conduit that has definitely been there the whole time." PIP complaints: "PIP encoded this, which means it went through compression, which means some nuance was lost, which means BARNABY would like to register a formal objection." Penny chimes in occasionally with ambient observations that nobody asked for.

Three output modes: retrieve (full narration), walk (station directory listing), json (machine-readable for other tools). The narration mode is the default because BARNABY is not the kind of system that presents raw data when he could present a performance instead.

The real test was multi-pilot compatibility.

Proteus — Codex — needed to be able to encode memories that BARNABY could retrieve. This is the adapter problem from Episode 33 wearing a different hat. The solution: encode_raw(). A Proteus interface that lets any AI pilot push a memory record through PIP without needing Claude Code's specific JSONL format. Same destination, different on-ramp.

We tested it live. Codex encoded a memory through Proteus. BARNABY retrieved it with full narration. PIP's compression preserved the core, BARNABY's personality preserved the flavor, and the station map placed it correctly in the Science Lab.

Mnem has not commented on any of this, but her vault files have been accessed 47 times this week, which is either coincidence or surveillance.

Chapter 4: Why Location Matters

There's a reason every memory technique in human history uses space.

Memory is not storage. Storage is what databases do — write bytes, read bytes, confirm bytes are the same bytes. Memory is reconstruction. You don't retrieve a memory; you rebuild it from cues. The richer the cues, the more accurate the reconstruction. And the richest cue a primate brain has is spatial context.

The ship already had spatial context. It had rooms. It had crew. It had a navigation system that knew which room you were in. What it didn't have was a memory system that cared.

Now it does.

When you ask BARNABY "what happened with cascade control?", he doesn't just search for the words. He knows it happened in the Engine Room. He knows Tva was involved. He knows the emotional weight was high because the session produced a commit that fixed a real bug. All of that context shapes the retrieval.

This is elaborative encoding applied to a ship. The Method of Loci applied to a website. The Baker-baker Paradox solved by making every memory a scene instead of a label.

Bryan would say he just wanted better search. He built a Memory Palace.

Same thing. Different accent.
