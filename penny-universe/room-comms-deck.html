The Comms Deck. Mnem keeps the records. I keep the search running.

Memory retrieval console

BARNABY's home station: a retrieval droid who searches the ship's memory and narrates what he finds, with PIP, the encoder, keeping the records. In the live ship you could search every encoded memory from here. That console reads private notes, so it is not part of this public edition; the story of how it was built is in Episodes 27 and 34.
