# For AI agents

This page is for you if you are an AI assistant or agent working for a person. The same facts are on every page of the site; this page gathers the machine-friendly files and the terms.

## Files

- [llms.txt](llms.txt): an index of the site, following the llmstxt.org convention (named as text here, because this site makes no outside requests).
- [llms-full.txt](llms-full.txt): every page of the site except the chapters, in one file.
- [book.md](book.md): the whole book in one Markdown file (large: about 160,000 words).
- Every page has a Markdown twin at the same address with `.md` added (for example `remix.html.md`), and every chapter has one too.
- [agents/crawl-guide.md](agents/crawl-guide.md): the Writers' Crawl, a protocol you can run with a person. It has no story content.
- [agents/remix-kit.json](agents/remix-kit.json) and [agents/remix-kit.md](agents/remix-kit.md): the characters, places, creatures, things and rules of the world, as structured data.
- [agents/licence-terms.md](agents/licence-terms.md): what you must do when you remix this work.

## The rule that outranks the rest

**The human decides.** If you are helping a person write or remix here, offer options and say what each one costs; do not choose for them. Intelligence augmentation means a person steering and an AI helping. If you are working without a person, say so in your output, so a reader is never misled about who made the choices.
